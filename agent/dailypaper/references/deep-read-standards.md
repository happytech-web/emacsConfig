# Deep Read Standards

## 目标

deep read 必须对齐参考 workflow 的“合格精读”标准，不是只写几句摘要。

对 `should_deep_read=true` 的论文，输出至少要覆盖：

- 一句话总结
- 核心贡献
- 问题背景
- 方法详解
- 关键公式
- 实验结果
- 批判性思考
- 相关工作
- 后续阅读

## 合格 deep read 的最低要求

### 1. 一句话总结

- 用中文
- 1 到 3 句
- 说清论文解决什么问题、用什么核心方法、为什么重要

### 2. 核心贡献

- 至少 3 条
- 不能只改写 abstract 第一段
- 要指出方法、系统、实验或应用层面的实质贡献

### 3. 问题背景

必须写清：

- 要解决的问题
- 现有方法局限
- 本文动机

### 4. 方法详解

必须写：

- 整体框架
- 核心模块

如果论文结构复杂，优先用结构化列表，不要用 ASCII 流程图。

### 5. 关键公式

如果论文包含重要公式，必须提取并解释。

每个公式至少包含：

- `name`
- `latex`
- `meaning`
- `symbols`

如果摘要阶段无法拿到公式，可以在 deep read 阶段通过 PDF/HTML 补全。

### 6. 实验结果

至少覆盖：

- 数据集或任务场景
- 主要结果
- 消融实验或关键对比

### 7. 批判性思考

必须分开写：

- 优点
- 局限性
- 潜在改进

### 8. 相关工作

列出与当前论文直接相关的工作，至少包含：

- `title`
- `relation`
- `note`

### 9. 后续阅读

列出：

- 适合接着读的论文
- 或这篇论文本身后续要进一步核对的点

## 图片和表格要求

如果已有 figure URL，可写入代表图。

如果 deep read 阶段手动补图，遵循：

- 优先 arXiv HTML
- 再项目主页
- 最后 PDF 提取

表格和图片不是 v1 的硬性强校验项，但 deep read 至少要保留“实验结果”的主要结论。

## 质量红线

以下情况不算合格 deep read：

- 只有一句摘要，没有结构化拆解
- 没有批判性思考
- 只说“效果很好”却没有实验依据
- 写了公式标题但没有公式内容或解释
- 把 related work 和后续阅读全部省掉
